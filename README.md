# BeautyTech-App: Skincare Ingredient Intelligence

A professional full-stack web application inspired by digital innovation in the beauty industry. This platform provides a luxury user experience for analyzing skincare ingredients and filtering products based on specific dermatological needs.

## 🚀 Features
- **Intelligent Ingredient Analysis:** Detailed breakdown of skincare components for transparency.
- **Dynamic Filtering:** Filter products seamlessly by skin type (Oily, Dry, Sensitive).
- **Responsive UI:** A high-end, gold-themed interface designed for premium branding.
- **RESTful Backend:** Scalable API built with Java Spring Boot.

## 🛠️ Tech Stack
- **Backend:** Java 17, Spring Boot, Spring Data JPA
- **Database:** H2 (In-memory database for rapid development)
- **Frontend:** JavaScript, CSS3 (Luxury Gold Theme), HTML5
- **Architecture:** Three-tier architecture (Controller, Service, Repository)

## 📁 Project Structure
- `src/main/java`: Contains the Spring Boot backend logic and entity models.
- `src/main/resources`: Contains the database configuration and frontend assets.

## ⚙️ How to Run
1. Clone the repository.
2. Ensure you have Maven installed.
3. Run `mvn spring-boot:run`.
4. Open your browser and navigate to `http://localhost:8080`.
